<h1>schemasafe</h1><p>A free, offline command-line scanner that reads a PostgreSQL migration <code>.sql</code> file and flags risky statements before you run them. It runs locally and sends no data anywhere.</p><h2>Usage</h2><pre>python -m schemasafe migration.sql</pre><p>Prints one line per finding. Exit code is 1 if anything is flagged, 0 if clean, so it works in CI.</p><h2>Rules</h2><ul><li><b>High:</b> DROP TABLE, DROP COLUMN, TRUNCATE, DELETE without WHERE</li><li><b>Medium:</b> UPDATE without WHERE, SET NOT NULL, ADD COLUMN NOT NULL without DEFAULT, ALTER COLUMN TYPE</li><li><b>Low:</b> CREATE INDEX without CONCURRENTLY, RENAME</li></ul><h2>Limitations</h2><p>This is a simple line-by-line regex scanner, not a full SQL parser. It can miss statements that span several lines and can produce false positives. Treat it as a quick safety net, not a guarantee. The test suite has not been run in CI yet.</p><h2>License</h2><p>MIT</p>
