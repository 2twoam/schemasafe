<h1>schemasafe</h1><p>A free, offline command-line scanner that reads a PostgreSQL migration <code>.sql</code> file and flags risky statements before you run them. It runs locally and sends no data anywhere.</p><h2>Usage</h2><pre>python -m schemasafe migration.sql</pre><p>Prints one line per finding. Exit code is 1 if anything is flagged, 0 if clean, so it works in CI.</p><h2>Rules</h2><ul><li><b>High:</b> DROP TABLE, DROP COLUMN, TRUNCATE, DELETE without WHERE</li><li><b>Medium:</b> UPDATE without WHERE, SET NOT NULL, ADD COLUMN NOT NULL without DEFAULT, ALTER COLUMN TYPE</li><li><b>Low:</b> CREATE INDEX without CONCURRENTLY, RENAME</li></ul><h2>How it works</h2><p>The scanner blanks out comments, string literals and dollar-quoted blocks (keeping line numbers), splits the file into statements on semicolons, and applies one regex per rule to each statement.</p><h2>Limitations</h2><ul><li>It is a regex scanner, not a full SQL parser. Treat it as a quick safety net, not a guarantee.</li><li>Code inside function bodies or DO blocks (dollar-quoted) is ignored, so risky statements there are not flagged.</li><li>Semicolons inside quoted identifiers can split a statement in the wrong place.</li><li>It only knows PostgreSQL-style syntax and a fixed set of rules.</li><li>Expect some false positives and false negatives.</li><li>The test suite is small, and there is no automated CI run yet.</li></ul><h2>License</h2><p>MIT</p>
